# 0.18.2 — what changed for an agent

## Behaviour that changed

- **The run log and `guardrails stats` say what the dry run and each mutant
  run did (#200).** On a locked stryker run the progress plugin now records,
  in the gate row's stryker part, `dryRunCounts` (how many tests the dry run
  ran, and in how many files) and `mutantRuns` (for the mutants stryker ran,
  not those reused: the tests they ran added up, their covering tests added
  up and how many listed them, how many were static, and their statuses by
  stryker's mutator name). Counts and mutator names only: no test name or
  path is kept. `guardrails stats` prints, per rung, the dry run's share of
  the lock time held, the median tests per gate, and the mutants run by
  mutator and status. Nothing in the gate's verdict changes, and the gate's
  dry run is unchanged.

## What to wire

Nothing. The fields appear in new run-log rows once this version runs a
locked gate; older rows lack them, though their dry-run share still shows.
